# Security Policy

## Supported Versions

Until WOW Forever is out for long enough and the add-on has been stress tested enough we I will keep the versioning as sub 1.x.x.

| Version | Supported          |
| ------- | ------------------ |
| 0.4.x   | :white_check_mark: |
| 0.4.x   | :x:                |

## Reporting a Vulnerability

If you find any vulnerabilities feel free to open an issue and point to any error messages, environments, or strange events that happened surrounding the error.

For any software developers, feel free to clone the repo and create a new branch, fix it and add a merge request. Any merges will be verified before I merge them to ensure safety and that it stays within my desired scope. I don't intend to open it up to auto-merge. AI is allowed as long as the code added has valid reasoning and logical explanations beyond just, "I asked Claude and it did it".
